# Decision Log & Source Mapping

This document acts as the **Architectural Decision Record (ADR)** for the peace plan. It tracks *why* specific mechanisms were chosen and *how* original source drafts were mapped into this canonical structure.

---

## 1. Source Document Mapping
This GitBook consolidates four disparate source drafts into one unified structure.

| Source Draft | Description | Mapped To |
| :--- | :--- | :--- |
| **Comprehensive Proposal** | Neutral, narrative framing of the full timeline. | **Overview** & **Concepts** |
| **v4 Operational Framework** | Technical sequencing, legal gating, and specific actions. | **Freeze** & **Legal Pathways** |
| **McCormick Off-Ramp Essay** | Persuasive "Realist" framing for US/EU audiences. | **Background/Essays** (D-008) |
| **Projet du Pape François** | Alternative religious/moral framing. | **Background/Essays** (D-008) |

---

## 2. Decision Register

| ID | Decision | Rationale | Impact |
| :--- | :--- | :--- | :--- |
| **D-001** | **Canonical Structure: Freeze–Vote–Rebuild** | Supports logical sequencing and verification-first gating (unlike "negotiate-then-ceasefire" models). | Core content organized into Chapters 02, 03, 04. |
| **D-002** | **Status-Neutral Framing** | Improves technical reviewability and prevents rejection based on perceived bias. | Advocacy moved to "Essays"; Core is strictly technical. |
| **D-003** | **Verification-First Gates** | Reduces reliance on "good faith"; makes progress auditable and reversible. | Added "Governance & Verification" chapter. |
| **D-004** | **Optional Vote-to-Border** | Preserves flexibility while mitigating gerrymandering risks. | Defined as a distinct, optional module in **Vote**. |
| **D-005** | **Displaced Persons (IDP) Requirement** | Exclusion encourages ethnic cleansing; inclusion is mandatory for legitimacy. | Built explicit electorate metrics in **Vote**. |
| **D-006** | **Auditable Reconstruction** | Corruption is a dominant failure mode; donors require traceability. | Added "Transparency Stack" to **Rebuild**. |
| **D-009** | **Data Governance Mandate** | Voting/monitoring data is sensitive; mishandling endangers lives. | Added privacy constraints to **Governance**. |
