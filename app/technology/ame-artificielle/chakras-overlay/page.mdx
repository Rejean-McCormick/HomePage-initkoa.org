# Chakras Overlay

## Why chakras here
ASE uses numerology as a **key**: a compact index that helps decode patterns.  
Chakras are used as a **second lens**—a somatic/energetic axis that often aligns with the 1–9 spectrum.

When multiple systems point to the same semantic region, that element is **brought forward** (higher salience).

## The overlay idea
We compute independent signals:

- **Numerology signal** (inverted Pythagorean): digit(s) → archetype traits
- **Chakra signal**: chakra(s) → themes + regulation style (grounding, will, voice, etc.)

Then we combine them:

- **Agreement** → amplify shared themes
- **Near-agreement** → keep, but lower confidence
- **Conflict** → keep both as tension, do not force a merge

## Minimal chakra ↔ spectrum mapping (starter)
This is a practical mapping you can tune later:

- **Root (Muladhara)** → 9 (grounding, survival, foundation)
- **Sacral (Svadhisthana)** → 8 (desire, creativity, relational flow)
- **Solar Plexus (Manipura)** → 7 (will, drive, self-definition)
- **Heart (Anahata)** → 6 (bonding, care, coherence)
- **Throat (Vishuddha)** → 5 (expression, mediation, movement)
- **Third Eye (Ajna)** → 3–4 (patterning, insight, structure)
- **Crown (Sahasrara)** → 1 (unity, meaning, synthesis)

Notes:
- **5** acts as a pivot/bridge in many systems: it’s useful as a “translator” zone.
- This mapping is **not doctrine**; it’s an engineering interface.

## What “brought forward” means (semantically)
ASE treats “salience” as:
- higher weighting of matching trait clusters
- stronger selection of matching vocabulary
- stronger influence on the reaction style (tone, certainty, pacing)

Example (conceptual):
- Numerology points to *compassion / humanitarian*
- Chakra overlay points to *heart coherence*
- Output: care/repair themes become primary; conflict themes become secondary.

## Handling conflicts (important)
If systems disagree:
- do **not** average into a bland middle
- represent it as **tension** (two active poles)
- let context choose which pole dominates per prompt

Output trace can expose:
- `overlay_agreement: high | medium | low`
- `dominant_chakra`
- `dominant_archetype_digit`
- `tension_pairs` (if any)

## Limits
- Overlays can create apophenia if not tested.
- Use validation: baselines, blind comparisons, and regression cases.
