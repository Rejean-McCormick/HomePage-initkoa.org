# The Knowledge Path

The kOA Curriculum is not designed to help students "pass tests." It is designed to help them **master reality**.
We have defined a core progression path ensuring every citizen masters the "Civic Stack": Literacy, Logic, Science, and Ethics.

<strong>Standardized Velocity:</strong> The curriculum is measured in "Active Hours." A 108h module represents ~3 weeks of full-time focus or 1 semester of part-time study.
