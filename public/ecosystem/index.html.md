Ecosystem / architecture

The final kOA system

A federation of independently owned capabilities, connected by explicit interfaces. Knowledge acquisition,
semantic authoring, learning, civic deliberation, operations and publication are separate responsibilities.

Target design, not deployment evidence. This catalogue describes the intended system.
A documented contract, build or code snapshot does not establish a qualified integration or public release.

Boundaries that matter

Skope/EncyK collects research; Médiathèque preserves sources; Framework and the Authoring Kit control semantic identity and local builds. Konnaxion owns civic decisions, while Orgo owns real Cases and Tasks. An educational preview cannot create work or write to Moodle without separate authority.

Koali Spaces is an optional presentation layer. Content qualification, publication consent and host activation are separate lifecycle decisions.
